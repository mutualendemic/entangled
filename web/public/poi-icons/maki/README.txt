Mapbox Maki map icons

Source: https://github.com/mapbox/maki/tree/main/icons
License: CC0 1.0 Universal (see LICENSE.txt).

These monochrome SVG icons are used as map POI markers. Several OSM POI
categories share a suitable Maki symbol where the set has no category-specific
icon (for example, hotels, guest houses, and hostels share `lodging.svg`).
